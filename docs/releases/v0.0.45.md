本版优化 macOS 更新后的重启速度，缩短菜单栏图标重新出现前的等待

- 修复更新后重启时的重复启动和额外等待，保持现有配置与启动方式
- 重启失败时保留正在运行的程序并提示原因，便于稍后重试
- 完善重启时的资源交接，确保本地端口和实例锁正常释放，保留日志输出

从旧版本首次升级到本版时，仍由旧程序执行重启；新的重启流程将在本版运行后生效

macOS 提供 Apple Silicon、Intel（macOS 14+）及 Legacy 通用版（macOS 12+），均使用 Developer ID 签名，并附 SHA256SUMS

Docker：`ghcr.io/pickrui/oixcloud-external-proxy-program:v0.0.45` 和 `latest`，支持 `linux/amd64`、`linux/arm64`
