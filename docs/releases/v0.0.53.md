# v0.0.53

- 修复 macOS 12/13 Legacy 版每次启动或重启都弹出「需要代理认证」的问题（#37）；窗口中的 127.0.0.1 随机端口属于 Helper 账号、订阅和更新请求使用的进程内直连服务，并非系统代理
- 该服务改为直接接受 Helper 自身发起的连接，其他进程仍须提供凭据；macOS 14+ 使用的 Main 版本原本不受影响
- 旧版本出现该窗口时，点「以后」不影响使用
- 仅 Legacy 有功能变化，Main 与 Linux 容器同步版本号

降级须知：v0.0.50 及更早版本无法读取钥匙串中的令牌，降级后需要重新登录；旧版本保存配置后再升级，也需要重新登录

macOS 12/13 的兼容构建不等于已完成对应系统的实机验证
