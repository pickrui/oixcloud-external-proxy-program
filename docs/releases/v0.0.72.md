## 中文

- 修复 HTTP 代理请求头解析不一致导致代理认证信息被转发的问题，并拒绝歧义或格式错误的请求
- 加强 SOCKS5 目标地址校验，修复 HTTP/3 状态码解析兼容性问题
- 更新密码学依赖，修复 Linux 处理畸形 RSA 证书时可能崩溃的问题
- 修正自动接入 Surge 配置项被误报为未知字段的问题
- Main 与 Legacy 同步更新，Legacy 保持 macOS 12 及以上支持

### 升级提醒

macOS 启动器或手动安装可在客户端检查更新；旧单文件安装可能先更新命令，重启后再迁移为完整应用，若显示「已安装…，点击重启」，请点击完成重启

Homebrew 用户运行 `brew update`、`brew upgrade oixcloud-external-proxy-program` 后重启服务

Docker 用户拉取新镜像并重新创建容器，保留原配置、端口映射和数据卷

## English

- Fix inconsistent HTTP proxy header parsing that could forward proxy credentials, and reject ambiguous or malformed requests
- Tighten SOCKS5 destination validation and fix HTTP/3 status decoding compatibility
- Update cryptographic dependencies to fix a possible crash when Linux parses malformed RSA certificates
- Stop incorrectly reporting the automatic Surge integration setting as an unknown configuration field
- Update Main and Legacy together, retaining macOS 12 and later support in Legacy

### Upgrade notes

Launcher and manual macOS installations can check for updates in the client. Older standalone installations may update the command first, then migrate to the complete app after restarting. If shown, select “Installed … — click to restart” to finish

Homebrew users should run `brew update` and `brew upgrade oixcloud-external-proxy-program`, then restart the service

Docker users should pull the new image and recreate the container, retaining existing configuration, port mappings and data volumes
