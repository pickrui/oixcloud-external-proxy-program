# v0.0.63

## 中文

- macOS 新增「客户端接入 › 节点更新后自动接入 Surge」开关，默认关闭，旧配置升级也保持关闭；开启并接入本机配置后，节点变化时自动应用，重启后补同步一次，相同节点不重复接入，连续更新合并处理，失败仅显示状态提示
- 改善切换网络、出口地址变化和系统唤醒后的连接恢复，及时清理旧解析与连接池；重复网络通知合并处理，断网期间不反复触发恢复
- 为 DNS 查询、双栈拨号与备用地址切换设置共享等待期限，取消或超时后及时关闭连接，避免旧连接继续占用资源
- 订阅或账户接口要求稍后重试时保留服务器给出的等待期限；临时失败按退避重试，明确失效的节点及时清除
- 过时节点的迟到拨号结果不再影响当前节点的健康状态或预连接
- 修复 Surge 配置中已有的 Helper 绕过规则未移至最前的问题，重复生成不再添加重复条目
- Legacy 同步适用的网络恢复、刷新与 Surge 规则修复，保持 macOS 12 及以上支持

### 升级

启动器或手动安装可用「工具 › 检查更新」。Homebrew 执行 `brew update`、`brew upgrade oixcloud-external-proxy-program`，然后重启服务。Docker 执行 `docker compose pull` 和 `docker compose up -d`

## English

- Add an opt-in macOS switch under Client Integration to reapply Surge after node updates. It stays off for new and existing configurations. After enabling it and importing the local profile, changed nodes are applied automatically, including one resync after restart. Unchanged nodes are skipped, consecutive updates are coalesced, and failures appear as status messages
- Improve recovery after network switches, egress changes and wake by retiring stale DNS and pooled connections. Coalesce duplicate notifications and defer recovery while offline
- Bound DNS queries, dual-stack dialing and fallback attempts by shared deadlines, closing canceled or timed-out connections promptly
- Preserve server-directed cooldowns across subscription and account retries. Back off after temporary failures and clear nodes confirmed to be unavailable
- Prevent late dial results for retired nodes from changing the active node's health or replenishing its connection pool
- Keep Helper bypass rules first in generated Surge profiles and avoid duplicate entries on repeated generation
- Apply compatible network recovery, refresh and Surge rule fixes to Legacy, retaining macOS 12 and later support

### Upgrade

Use Tools > Check for updates in the launcher or manual installation. For Homebrew, run `brew update`, `brew upgrade oixcloud-external-proxy-program`, and restart the service. For Docker, run `docker compose pull` and `docker compose up -d`
