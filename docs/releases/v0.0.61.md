# v0.0.61

## 中文

- 优化本地配置读取：缓存远端模板、合并并发刷新，并为本机导入保留完整等待预算，修复慢请求引起的重复等待和导入超时；Legacy 同步修复
- macOS 14 及以上和 Linux 的托管节点 DNS 支持并发使用多个 DoT、DoH 入口，自动采用可用结果；支持面板签名下发和更新解析入口，继续保留查询签名与严格证书校验，不回退到明文 DNS
- 为解析入口地址的冷启动查询预留时间，将托管 DNS 总预算从 4 秒调整为 9 秒；macOS 本机代理诊断同步覆盖 DNS、节点握手和 HTTP 检测的等待时间
- 修复地址解析、TCP 连接失败被误报为 TLS 握手失败的问题，保留系统错误码，便于区分解析失败、连接拒绝和 TLS 异常；Legacy 同步适用的 TCP／TLS 错误保留修复
- macOS 14 及以上新增「客户端接入 › MITM 证书」开关，可按需将账户证书写入 Surge 配置；默认关闭，局域网访问须通过鉴权才能读取证书等账户信息
- 修复部分系统下 CRLF 换行导致未鉴权客户端的账户信息过滤不完整的问题

### 升级

- 启动器或手动安装可用「工具 › 检查更新」
- Homebrew 执行 `brew update`、`brew upgrade oixcloud-external-proxy-program`，然后重启服务
- Docker 执行 `docker compose pull` 和 `docker compose up -d`

## English

- Cache remote profile templates, coalesce concurrent refreshes, and give local imports their full request budget. Fix repeated waits and import timeouts on slow requests, including Legacy
- On macOS 14+ and Linux, race multiple managed DoT and DoH resolvers and use an available answer. Accept resolver-list updates only with the panel's verified signature. Keep signed queries, strict certificate checks, and no plaintext DNS fallback
- Allow cold resolver-address lookups within a 9-second managed DNS budget, replacing the previous 4-second limit. Align macOS local proxy diagnostics with the DNS, node handshake, and HTTP probe budgets
- Preserve DNS and TCP failures and their system error codes instead of reporting them as TLS handshake failures. Legacy receives the applicable TCP/TLS error-preservation fixes
- On macOS 14+, add Client Setup > MITM certificate to include the account's CA in Surge profiles when enabled. It is off by default; LAN clients need authentication to read certificate and other account material
- Fix incomplete filtering of account material for unauthenticated clients when CRLF line endings are used on some systems

### Upgrade

Use Tools > Check for updates in the launcher or manual installation. For Homebrew, run `brew update`, `brew upgrade oixcloud-external-proxy-program`, and restart the service. For Docker, run `docker compose pull` and `docker compose up -d`
