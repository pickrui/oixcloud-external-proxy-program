本版加入 Snell v6 + ECH，并完善流结束校验和连接复用，保留 Snell v4 / v5 TCP 兼容

- Snell v6 接入版本专用 ALPN、Identity v2、默认加密整形、UDP 整包与连接复用，支持 TCP 和 HTTP/3
- 托管订阅声明 v6 能力，面板可向新版客户端下发 v6 节点；使用前须更新服务端，原有 ECH 密钥和证书可继续使用
- 拒绝截断的加密记录、不完整的服务端回复及结束标记后的多余数据，协议错误立即关闭连接
- 仅在双向结束标记都完成后复用连接，避免发送失败或超时的连接进入连接池
- 统一 v6 配置校验，拒绝不支持或格式错误的协议版本，减少整形过程中的临时分配，整理第三方声明和测试资源

省略传输设置时仍使用 TCP，`auto` 保留 HTTP/3 与 TCP 竞速，`h3` 保持不回退；既有程序文件名、配置目录与更新地址保持兼容

macOS 提供 Apple Silicon、Intel（macOS 14+）及 Legacy 通用版（macOS 12+），均使用 Developer ID 签名，并附 SHA256SUMS

Docker：`ghcr.io/pickrui/oixcloud-external-proxy-program:v0.0.43` 和 `latest`，支持 `linux/amd64`、`linux/arm64`
