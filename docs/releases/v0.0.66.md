## 中文

- 修复 Homebrew 安装后部分启动入口无法正常启动的问题
- macOS 菜单栏程序统一显示为 oixCloud Helper，更新提示明确标注应用名称
- 提供 Main 与 Legacy 完整应用包，支持现有安装在线迁移，保留原命令、Homebrew 和启动器入口
- 应用更新仅在对应完整应用包就绪后提示
- 常规维护更新，macOS 主版本、Legacy 与 Docker 同步更新

### 升级

启动器或手动安装可用「工具 › 检查更新」；Homebrew 执行 `brew update`、`brew upgrade oixcloud-external-proxy-program`，然后重启服务

Docker 用户先同步部署目录的 `compose.yaml`，按 `/list` 实际端口核对映射，再执行 `docker compose pull`、`docker compose up -d --force-recreate helper`，保留现有配置与数据卷

## English

- Fix startup failures through some Homebrew launch paths
- The macOS menu bar app now uses the oixCloud Helper name, including update prompts
- Provide complete Main and Legacy app bundles with online migration for existing installations, retaining command, Homebrew and launcher entry points
- Offer app updates only when the matching complete app bundle is available
- Routine maintenance update across macOS main, Legacy and Docker

### Upgrade

Use Tools > Check for updates in the launcher or manual installation. For Homebrew, run `brew update`, `brew upgrade oixcloud-external-proxy-program`, and restart the service

For Docker, update the deployment's `compose.yaml` and check port mappings against `/list`, then run `docker compose pull` and `docker compose up -d --force-recreate helper`. Keep the existing configuration and data volume
