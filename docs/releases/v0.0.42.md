本版优化 Snell 自动传输选择，改善 HTTP/3 不可用时的连接等待，并整理连接生命周期与冗余实现

- `auto` 先尝试 HTTP/3，首次连接等待 250 毫秒后并行启动 TCP；已有 QUIC 会话时，根据平滑 RTT 调整等待时间（100 毫秒～1 秒），先完成传输握手的一路胜出
- HTTP/3 提前失败时立即启动 TCP；TCP 胜出后，尚未完成的 H3 尝试最多运行到 2 秒建立上限，实际失败进入 30 秒冷却，迟到的成功保留可复用的 QUIC 会话并回收多余流
- 修正 TLS 建连、取消与握手完成时的连接所有权处理；统一普通拨号和预热的协议、身份版本与证书校验，并清理未使用的 HTTP/3 接口和重复逻辑
- 容器发布强制包含 Linux amd64、arm64，防止单架构镜像意外覆盖发布标签

省略传输设置时仍使用 TCP，`h3` 保持不回退；传输竞速仅发生在 Snell 鉴权及业务数据发送前，不重放请求，现有配置和安装路径保持兼容

macOS 提供 Apple Silicon、Intel（macOS 14+）及 Legacy 通用版（macOS 12+），均使用 Developer ID 签名，并附 SHA256SUMS

Docker：`ghcr.io/pickrui/oixcloud-external-proxy-program:v0.0.42` 和 `latest`，支持 `linux/amd64`、`linux/arm64`
