# v0.0.51

- 登录改用独立设置窗口，支持 Access Token 和邮箱密码两种方式
- macOS 将保存的访问令牌与节点缓存密钥移入登录钥匙串，减少配置文件中的敏感信息
- 更新下载优先使用 Helper 出口，显示下载进度并支持取消
- 按节点分别判断连接失败并限制重复日志，减少单个节点故障对其他节点的影响
- Main 与 macOS 12+ Legacy 同步更新，Linux 容器同步连接故障判定改进

降级须知：v0.0.50 及更早版本无法读取钥匙串中的令牌，降级后需要重新登录；旧版本保存配置后再升级，也需要重新登录

macOS 12/13 的兼容构建不等于已完成对应系统的实机验证
