# v0.0.50

- macOS 诊断新增 IPv4 / IPv6 出口、新 DNS 查询、隧道建立和 HTTP 往返耗时
- 逐节点模式抽检最多 5 个映射，检查实际 SOCKS5 / HTTP 入口、鉴权和响应状态，不再依赖当前节点
- 显示检测进度，区分超时、TLS/ECH、鉴权及 HTTP 错误；仅完整 HTTP 204 视为测速成功
- Main 与 macOS 12+ Legacy 同步更新

本次增强故障定位能力，尚不能确认修复所有连接异常；发生故障时请运行诊断并提供同期日志

发布加固说明：Linux 镜像使用 BLA 1.1.0；macOS 的 BLA 输出未通过重新签名验证，因此 macOS 产物沿用 strip 与 Developer ID 签名，本版本不声称完成 macOS BLA 加固
