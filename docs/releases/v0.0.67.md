## 中文

- 优化订阅刷新，配置未变化时减少重复处理，定时检查照常进行
- 检查时间、流量与到期信息继续更新，配置变化或上次处理失败时仍会正常更新或重试

### 升级提醒

macOS 启动器或手动安装可在客户端检查更新；旧单文件安装可能先更新命令，重启后再迁移为完整应用。若显示「已安装…，点击重启」，请点击完成重启

Homebrew 用户运行 `brew update`、`brew upgrade oixcloud-external-proxy-program` 后重启服务

Docker 用户先同步部署目录的 `compose.yaml`，按 `/list` 实际端口核对映射，再拉取镜像并重新创建容器；保留原配置和数据卷

## English

- Optimize subscription refreshes to avoid redundant work when the configuration is unchanged, while keeping scheduled checks
- Continue updating check times, traffic usage and expiry details, and apply changes or retry failed operations as needed

### Upgrade notes

Launcher and manual macOS installations can check for updates in the client. Older standalone installations may update the command first, then migrate to the complete app after restarting. If shown, select “Installed … — click to restart” to finish

Homebrew users should run `brew update` and `brew upgrade oixcloud-external-proxy-program`, then restart the service

Docker users should first synchronize the deployment directory’s `compose.yaml`, check port mappings against the actual `/list` ports, then pull and recreate the container, retaining existing configuration and data volumes
