# v0.0.65

## 中文

- 改善部分网络下的节点连接恢复，修复解析服务地址不可达时无法继续连接的问题
- 修复并发恢复时短时限请求影响其他请求的问题，并统一后续尝试的总等待时限
- macOS 主版本、Legacy 与 Docker 同步更新，Legacy 继续支持 macOS 12 及以上

### 升级

启动器或手动安装可用「工具 › 检查更新」；Homebrew 执行 `brew update`、`brew upgrade oixcloud-external-proxy-program`，然后重启服务

Docker 用户先同步部署目录的 `compose.yaml`，按 `/list` 实际端口核对映射，再执行 `docker compose pull`、`docker compose up -d --force-recreate helper`，保留现有配置与数据卷

## English

- Improve connection recovery on networks where the resolver service address cannot be reached
- Prevent requests with short time limits from cutting off recovery shared by other requests, and keep subsequent attempts within the overall time limit
- Update macOS main, Legacy and Docker together, retaining macOS 12 and later support in Legacy

### Upgrade

Use Tools > Check for updates in the launcher or manual installation. For Homebrew, run `brew update`, `brew upgrade oixcloud-external-proxy-program`, and restart the service

For Docker, update the deployment’s `compose.yaml` and check port mappings against `/list`, then run `docker compose pull` and `docker compose up -d --force-recreate helper`. Keep the existing configuration and data volume
