# v0.0.58

## 中文

- 改善多连接场景下的稳定性和资源占用，减少断连
- 修复上传结束后，下载或长响应可能提前中断的问题
- 改善 UDP 转发响应，避免新连接拖慢已有通信
- 优化并发请求时的域名解析效率和连接回收

### 升级

启动器或手动安装可使用「工具 › 检查更新」

Homebrew：

```bash
brew update
brew upgrade oixcloud-external-proxy-program
brew services restart oixcloud-external-proxy-program
```

Docker：`docker compose pull`，然后 `docker compose up -d`

### 验证范围

macOS 和 Linux 的本地回环测试均覆盖 1000 条 TCP 连接连续收发 10 分钟，以及 1000 个 UDP 关联和 1000 个未完成握手；另外完成分 30 批共 3 万次连接建立和回收

压测使用模拟上游，结果不代表真实节点的完整传输开销；macOS 12／13 未新增实机验证

## English

- Improve stability and resource usage with many simultaneous connections, reducing disconnections
- Fix downloads and long responses being cut off after the client finishes uploading
- Keep existing UDP traffic responsive while establishing new connections
- Improve DNS lookup efficiency and connection cleanup under concurrent workloads

### Upgrade

Launcher/manual installations can use Tools > Check for updates

For Homebrew, run `brew update`, `brew upgrade oixcloud-external-proxy-program`, then `brew services restart oixcloud-external-proxy-program`

For Docker, run `docker compose pull`, then `docker compose up -d`

### Validation scope

Local loopback tests on macOS and Linux covered 1000 TCP connections exchanging data continuously for 10 minutes, 1000 UDP associations and 1000 incomplete handshakes. An additional 30 batches verified 30,000 connection creations and teardowns

The load tests used a synthetic upstream and do not measure the full cost of real-node transport. No additional physical macOS 12/13 testing was performed
