修复 v0.0.33 多端口映射恢复中的启动和注销问题

- 配置服务先绑定端口，再恢复旧映射，避免更改订阅端口后因旧映射抢占而启动失败
- 注销会清空映射保存状态，重新登录相同节点后仍会保存端口分配
- 注销清理与后台保存按顺序完成，避免注销后重新生成旧账号映射文件
- 首次节点绑定前发生注销、认证失败或节点失效时，立即唤醒等待中的连接，不再等待剩余宽限期

macOS 提供 Apple Silicon、Intel（macOS 14+）和 Legacy 通用版本（macOS 12+），均使用 Developer ID 签名，可用 `SHA256SUMS` 校验

Legacy 的系统要求与 v0.0.33 一致；已在当前 macOS 验证兼容路径，未在 macOS 12–13 真机验证

Docker：`ghcr.io/pickrui/oixcloud-external-proxy-program:v0.0.34`，同时更新 `latest`，支持 `linux/amd64` 和 `linux/arm64`
