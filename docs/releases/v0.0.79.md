- 在网页或 Telegram 拒绝设备登记后，Helper 会停止等待并清除窗口里的旧确认码，待原请求过期后，可在菜单栏重新获取确认码，或再次运行 `--enroll-device`
- 拉取节点时使用账户已保存的节点筛选，未设置筛选时由面板智能优选

从 v0.0.76 或更早版本更新时，如果点击「立即重启」后菜单栏图标没有出现，请手动打开一次 oixCloud Helper

从 v0.0.73 或更早版本升级后，请先联网刷新一次节点，刷新成功后，同一账号在暂时离线时仍可使用已缓存的节点

macOS 12／13 请使用 Legacy 版本，macOS 14 及以上按芯片类型选择对应版本
