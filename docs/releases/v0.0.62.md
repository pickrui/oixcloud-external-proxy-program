# v0.0.62

## 中文

- 移除 SOCKS5 拨号前最长 100 毫秒的首包等待，立即建立上游连接；已经到达的首包仍合并发送，支持服务端先发数据的协议
- 多端口映射按实际使用的节点补足预连接，复用本次拨号选定的地址，减少重复解析和重新建连的等待
- 后台预连接并发根据 CPU 自动选择 8–32 条，Linux 同时考虑可见的 CPU 集合及 cgroup v2 配额；保持连接池总容量限制，避免批量测速时后台握手过度挤占前台请求
- Legacy 同步上述 SOCKS5、映射预连接和硬件并发调整

### 升级

- 启动器或手动安装可用「工具 › 检查更新」
- Homebrew 执行 `brew update`、`brew upgrade oixcloud-external-proxy-program`，然后重启服务
- Docker 执行 `docker compose pull` 和 `docker compose up -d`

## English

- Remove the wait of up to 100 ms for the first SOCKS5 payload before dialing upstream. Dial immediately, coalesce data already available, and support server-first protocols
- Replenish preconnections for mapped nodes as they are used, reusing the address selected by the successful dial to avoid repeated resolution and connection setup
- Automatically size background preconnection concurrency from 8 to 32 using the CPU count. On Linux, also account for visible CPU sets and cgroup v2 quotas. Retain the total pool capacity limit to reduce interference with foreground requests during batch probes
- Apply the SOCKS5, mapped preconnection, and CPU-based concurrency improvements to Legacy

### Upgrade

Use Tools > Check for updates in the launcher or manual installation. For Homebrew, run `brew update`, `brew upgrade oixcloud-external-proxy-program`, and restart the service. For Docker, run `docker compose pull` and `docker compose up -d`
