- 首次获取托管节点时如需批准，可在菜单栏选择「批准这台设备…」，按提示在网页或 Telegram 确认，无界面的设备可运行 `--enroll-device` 获取确认码
- 切换账号时清除旧账号的 DNS 缓存，避免重新登录后短暂使用旧的解析结果
- 托管节点的 IPv4 地址先返回时，Helper 最多再等 IPv6 100 毫秒即可开始连接，同一域名的并发连接共享这段等待时间
- 收到超过 8 项的托管 DNS 配置时，Helper 会保留现有配置，升级前已缓存的列表若超过此上限，则使用内置配置

从 v0.0.76 或更早版本更新时，如果点击「立即重启」后菜单栏图标没有出现，请手动打开一次 oixCloud Helper

从 v0.0.73 或更早版本升级后，请先联网刷新一次节点，刷新成功后，同一账号在暂时离线时仍可使用已缓存的节点

macOS 12／13 请使用 Legacy 版本，macOS 14 及以上按芯片类型选择对应版本
